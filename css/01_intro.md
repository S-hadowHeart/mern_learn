## Introduction to CSS

Websites are a crucial part of a brand’s online presence.
A well-designed website should focus on **users** and provide a **smooth and pleasant user experience**.

**CSS (Cascading Style Sheets)** helps developers style websites so they look visually appealing and user-friendly.

---

## What is CSS?

* CSS stands for **Cascading Style Sheets**
* It is used to **style and design HTML elements**
* CSS controls:

  * Colors
  * Layout
  * Fonts
  * Spacing
  * Animations
* It defines **how HTML elements appear on the screen**

---

## Why CSS?

* CSS is a **core technology of web development**
* It controls the **presentation layer** of HTML documents
* Helps separate **content (HTML)** from **design (CSS)**
* Works on all devices:

  * Desktop
  * Tablet
  * Mobile
* Lightweight and relatively easy to learn
* Essential skill for every web developer

---

## What Can CSS Do?

* Add styling to plain HTML pages
* Improve visual appearance of websites
* Change layout and design without touching HTML
* Make websites responsive and interactive
* Completely redesign a website using only CSS changes

---

## Advantages of Using CSS

* **Saves development time**
* **Faster page loading**
* **Easy maintenance**
* **More advanced styling than HTML**
* **Cross-device compatibility**
* **Consistent global web standards**
* **Reusable and scalable styles**

---

### Quick Reminder

> **HTML gives structure, CSS adds beauty.**
