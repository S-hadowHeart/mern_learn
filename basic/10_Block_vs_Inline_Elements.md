## Block-Level Elements

A block-level element always starts on a new line.

Browsers add default margin before and after a block-level element.

A block-level element occupies the full available width of its parent.

Block-level elements can contain inline elements and other block-level elements.

`<p>` and `<div>` are commonly used block-level elements.

### Popular Block-Level Elements

```html
<div>
<p>
<h1> to <h6>
<ul>
<ol>
<li>
<section>
<article>
<header>
<footer>
<nav>
<main>
<aside>
<form>
<table>
<hr>
```

---

## Inline Elements

An inline element does not start on a new line.

It uses only the space required by its content.

An inline element cannot contain block-level elements.

Inline elements can contain text and other inline elements.

### Popular Inline Elements

```html
<span>
<a>
<img>
<strong>
<b>
<em>
<i>
<small>
<mark>
<label>
<input>
<button>
<code>
<sub>
<sup>
```

---

## Block vs Inline (Quick Difference)

| Block Elements               | Inline Elements          |
| ---------------------------- | ------------------------ |
| Start on new line            | Do not start on new line |
| Full width                   | Content width only       |
| Can contain block and inline | Cannot contain block     |
