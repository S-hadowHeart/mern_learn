## JavaScript

- Other programming languages can be **static** or **dynamic**, but **JavaScript is loosely typed**.
- Do **not compare JavaScript directly** with other programming languages; doing so can prevent proper understanding of JS.
- **JavaScript is one of the most popular programming languages** in the world.

## ECMAScript (ES6)

- **ECMAScript (ES6)** is a standard that defines rules for writing JavaScript.
- Earlier, developers faced issues where the **same code had to be written twice** to work in different browsers.
- **ES6 solved this problem** by providing a common standard for scripting languages.
- **ES6 = ECMAScript 6 (released in 2015)**.
- ES6 is considered one of the **best standards for modern scripting**.

## History of JavaScript

- **1995**: First name was **Mocha**.
- **1996**: Renamed to **LiveScript**.
- It was **not very popular**, so the name was changed to **JavaScript**.
- The name **JavaScript** was chosen because **Java was very popular** at that time.
